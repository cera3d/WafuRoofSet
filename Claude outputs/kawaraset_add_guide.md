# 瓦セットの追加導入方法

BOOTHなどで個別に購入した瓦セット(zip)を、WafuRoofSetアドオンに追加する手順です。
(S型瓦・Ｊ型_一文字瓦など、本体アドオンとは別売りの瓦セット全般に共通の手順です)

## 1. 前提

WafuRoofSetアドオン本体が、あらかじめBlenderにインストール・有効化されている必要があります。
まだの場合は先に本体アドオンをインストールしてください。

## 2. 手順

### ① zipを展開する

購入したzipを展開すると、`.blend`ファイルが1つ出てきます。

### ② WafuRoofSetの「KawaraSet」フォルダを開く

瓦セットは、WafuRoofSetアドオンのインストール先にある`KawaraSet`という名前のフォルダに置きます。

- **Windows**: エクスプローラーのアドレス欄に次を貼り付けて開いてください(`<バージョン>`はお使いのBlenderのバージョン番号、例: `5.1`)。

  ```
  %APPDATA%\Blender Foundation\Blender\<バージョン>\extensions\user_default\WafuRoofSet\KawaraSet
  ```

- **Mac**: Finderで「移動」→「フォルダへ移動」を選び、次を入力してください。

  ```
  ~/Library/Application Support/Blender/<バージョン>/extensions/user_default/WafuRoofSet/KawaraSet
  ```

すでに`kawara_sample.blend`などが入っているフォルダです。

### ③ ①の.blendファイルをこのフォルダにコピーする

他のファイルと同じ階層に、そのままコピー&ペーストしてください。展開・移動以外の作業は不要です。

### ④ Blenderで読み込む

Blenderの再起動は不要です。

1. 3Dビューポート右側のNパネルから「瓦屋根セット」タブ→「瓦」を開く
2. 一番上のファイル選択ドロップダウンを開き直す(コピーしたファイル名が候補に増えているはずです)
3. 追加した瓦セットのファイル名を選択
4. 「選択したファイルを読み込む」を押す

これで、その瓦セットのコレクションがシーンにLink(参照)で読み込まれます。あとは通常通り「1. 瓦コレクションを指定」で選んで使ってください。

## 3. 注意点

- **コピーした.blendファイルは、読み込んだ後も`KawaraSet`フォルダから移動・削除しないでください。** 瓦セットはコピー(Append)ではなくLink(参照)で読み込まれるため、元のファイルが無くなると、後でプロジェクトを開いたときに瓦が読み込めなくなります。
- ファイルを最新版に差し替える場合(アップデート配布など)は、同じファイル名のまま`KawaraSet`フォルダ内のファイルを上書きしてください。既にそのファイルを読み込んで使っているプロジェクト側は、次に開いたときに自動で新しい内容に更新されます。
