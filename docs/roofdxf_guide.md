# 屋根面作成(DXF取込)Readme

WafuRoofSetの「屋根面作成」機能は、CADで描いた2D図面(DXF)の線を読み込み、軒先・大棟などの意味を線に割り当てることで、勾配・高さを自動計算した3Dの屋根面(野地板面)を生成する機能です。

パネルの「1〜8」の番号は、そのまま作業の順番になっています。

## 全体の流れ

1. 読み込み — DXFファイルを開き、使うレイヤーを選んで線メッシュ(RoofLines)として取り込む
2. 自動判定(任意) — 孤立した線(矢印など)を除外し、軒先/屋根の線を自動で仮判定する
3. 線を指定 — 編集モードで線を選択し、軒先・大棟・屋根の線・軒梁中心線のいずれかに設定する
4. 線のオフセット — 選択した線を平行移動する(ケラバ・軒の出を見込んで面を縮小する用途など)
5. 不要な線を整理 — どの種類にも設定されなかった線を削除する
6. 勾配 — 勾配(x/10)または角度(度)を入力する。片方を変えるともう片方も連動する
7. 厚み — 屋根の厚みと、押し出す方向(鉛直/直角)を指定する
8. 屋根面を生成 — ここまでの設定から、実際の3Dメッシュ(Roofオブジェクト)を生成する

## 1. 読み込み

- DXFの単位(mm/cm/m)を指定してファイルを開くと、含まれるレイヤー名と線の本数が一覧表示される
- 使うレイヤーだけチェックを入れて読み込む(不要なレイヤー、例えば寸法線や文字のレイヤーは外す)
- 円弧・円は直線に分割して読み込まれる。「円弧の分割数」を増やすほど滑らかになるが、線の本数(=処理負荷)も増える
- 読み込み後は「RoofLines」という編集用の線メッシュができる。以降の作業はこのオブジェクトの編集モードで行う

## 2. 自動判定(任意)

孤立した小さな線の塊(矢印・記号など)を自動的に除外し、残った線を面ごとに分割して、1つの面にしか接していない線を「軒先」、2つの面に接している線を「屋根の線」として仮に自動分類します。

あくまで機械的なルール(接している面の数)による仮判定なので、**実行後は必ず目視で確認してください**。大棟や軒梁中心線はこの自動判定では設定されないので、必要な箇所は手動で設定し直す必要があります。

## 3. 線を指定

編集モードで対象の線(辺)を選択し、以下のいずれかに設定します。色は3Dビューポート上でリアルタイムに表示されます。

| 種類 | 色 | 意味 |
|---|---|---|
| 軒先 | 赤 | 屋根の一番低い端。ここから離れるほど高くなる(高さ計算の基準になりうる) |
| 大棟 | オレンジ | 屋根の一番高い部分。ここから離れるほど低くなる(高さ計算の基準になりうる) |
| 屋根の線 | 青 | 面の境界にはなるが、高さの基準にはならない線(隅棟や谷など) |
| 軒梁中心線 | 紫 | 面の境界には使わない。生成後の高さ(Z位置)を合わせる基準専用の線 |
| 不要 | グレー | 上記のいずれでもない(最終的に削除される) |

軒梁中心線は**1本のみ**設定してください(複数設定した場合は全頂点の平均位置が使われます)。

## 4. 線のオフセット

選択した辺を、その辺の法線方向(2D平面内)に指定距離だけ平行移動します。共有する頂点は接続する辺の法線の平均方向に動きます。

- 勾配がある屋根では、水平方向の移動距離と屋根面に沿った実寸の距離は一致しません。実際にどれだけ動かすべきかは勾配を考慮して決めてください
- 一部の辺だけをオフセットすると、その面の高さ計算がズレる原因になります(面全体を囲む線をまとめて動かすようにしてください)
- **瓦を敷く際は、ケラバ・軒の出(オーバーハング)を考慮して、屋根面(野地板面)を実際の仕上がりより一回り小さく作っておくのがおすすめです。** 瓦システム側のケラバ・軒のオーバーハング設定は、面の外側に瓦を追加で敷くためのものであり、面の形そのものを変更するわけではないためです。CADの線をそのまま面にすると、出の分だけ面が大きくなりすぎることが多いので、この機能で事前に縮小しておく使い方を想定しています。

## 5. 不要な線を整理

「不要(未分類)」のままの線と、孤立した頂点をまとめて削除します。生成前に済ませておくと、面の検出がしやすくなります。

## 6. 勾配

「勾配(x/10)」と「勾配(角度°)」は連動しています。どちらか一方を入力すればもう片方も自動で計算されます(例: 4寸勾配 = 約21.8°)。

## 7. 厚み

- 屋根の厚み(mm)を指定します
- 押し出す方向は「鉛直(Z軸)」と「直角(法線)」から選べます
  - 鉛直: 真下に押し出す(軒先の断面が垂直になる、一般的な屋根の見え方)
  - 直角: 屋根面に対して垂直に押し出す(ソリッド化モディファイヤと同じ効果)

## 8. 屋根面を生成

ここまでの設定をもとに、実際の3Dメッシュ(「Roof」オブジェクト)を生成します。

### 高さ計算の仕組み(重要)

- 図面上の線(軒先・大棟・屋根の線)から、内部の計算処理で閉じた面を検出します。線がきちんと閉じていないと面として認識されないので、その場合はまず線のつながりを確認してください
- 各面ごとに、その面の境界に含まれる**大棟**があれば、大棟からの距離をもとに高さを計算します(離れるほど低くなる)。大棟が優先されるのは、軒先の高さが左右で異なる非対称な屋根にも対応するためです
- その面に大棟が含まれない場合は、その面自身の**軒先**からの距離で高さを計算します(離れるほど高くなる)
- その面に軒先も大棟も含まれない場合は、図面全体の軒先の中から一番近いものを代用します。この場合、生成後のメッセージに「自分の軒先がない面: ○件」という警告が出るので、該当の面は形状が意図通りか確認してください

### 高さ基準線(軒梁中心線)による自動調整

「軒梁中心線」を設定しておくと、生成後にその線の位置(XY座標の平均)から真上に光線を飛ばし、屋根の下面と最初にぶつかった高さがZ=0になるよう、屋根全体を自動でZ方向に移動します。設定していない場合はこの自動調整は行われません(生成された屋根はそのままの高さになります)。

## よくある注意点・制限

- 線が閉じたループになっていないと面として検出されません(閉じ忘れ、線の重複・隙間に注意)
- 自動判定はあくまで補助機能です。必ず目視で確認し、大棟・軒梁中心線は手動で設定してください
- オフセットは水平面内での移動なので、勾配のある屋根では実寸との差を考慮する必要があります
- 生成時に「自分の軒先がない面」の警告が出た場合は、その面の周囲の線の分類(軒先/大棟/屋根の線)を見直してください

## 生成前チェックリスト

- [ ] 不要なレイヤー(寸法線・文字など)は読み込んでいないか
- [ ] 全ての面が、軒先または大棟のどちらかを含んでいるか(自動判定+目視確認)
- [ ] 軒梁中心線は1本だけ設定されているか(高さを自動調整したい場合)
- [ ] 線はきちんと閉じているか(隙間・重複がないか)
- [ ] 瓦を敷く予定なら、ケラバ・軒の出を見込んで面を縮小したか
- [ ] 勾配・厚み・押し出し方向は意図通りか
