# WafuRoofSet(瓦屋根セット)

Blender用アドオン。CADの2D図面(DXF)から屋根面(野地板面)を自動生成し、そこに和瓦(平瓦・軒瓦・袖瓦・棟瓦・隅棟瓦など)を自動で敷き詰めます。

パース(完成予想図)制作を主な用途として作られています。施工図面としての寸法精度ではなく、「見た目として違和感のない和瓦屋根を、手早く作る」ことを目的にしています。

## できること

- **屋根面作成(DXF取込)**: CADの2D図面(軒先・大棟・屋根の線などを指定した線)から、勾配・高さを自動計算して3Dの屋根面を生成
- **瓦の自動配置**: 屋根面を選ぶだけで、平瓦・軒瓦・左右袖瓦を働き幅・働き長さに応じて自動配置
- **役物の自動配置**: 棟・隅棟のラインに沿って棟瓦・隅棟瓦を配置し、端部には巴瓦・鬼瓦を自動判定して配置
- **千鳥敷き**: 平瓦を1段おきに半ピッチずらす、F型瓦などでよく見る敷き方に対応
- **はみ出し処理**: ケラバ・軒先からはみ出た瓦を、実際の屋根の形状に沿って自動カット
- **隅棟・谷の処理**: 単純な四角形ではない屋根面(隅棟・谷が収束する角など)でも、瓦が途切れないよう配置計算側で補正

## 対応している瓦セットのタイプ

瓦の3Dモデル自体(瓦セット)はこのアドオンには含まれません。別途用意した瓦セット(Blenderコレクション)を読み込んで使います。

- **かぶせタイプ**(F型瓦など、洋瓦風): 割付の厳密さをあまり求めないセットでも問題なく使えます
- **絡む(敷く)タイプ**(和瓦・万十瓦など): 袖瓦と平瓦が正確に噛み合う必要があるセットにも対応(`kawara_flat_offset_mm`などの調整用プロパティあり)

自分で瓦セットを作る場合は [`docs/kawaraset_guide.md`](docs/kawaraset_guide.md) を参照してください。原点の決め方・寸法の関係など、セット作成時に必要なルールをまとめています。

屋根面作成(DXF取込)の使い方は [`docs/roofdxf_guide.md`](docs/roofdxf_guide.md) を参照してください。

## インストール

1. Blender 4.2以降を推奨(Extensions対応版)
2. 本リポジトリを ZIP でダウンロード
3. Blenderの拡張機能(Extensions)/アドオン管理画面から、ダウンロードしたZIPをインストール

## 既知の制限

- **凹形状(L字など)は正式サポート外**: 平瓦の配置・カット自体は凹形状でも動きますが、軒瓦・袖瓦の「どの辺が軒先/ケラバか」の判定は単純な凸四角形が前提です
- **隅棟と谷は区別していません**: `kawara_role`に「隅棟(hip)」の役割はありますが、谷(valley)専用の役割はなく、内部的には同じ「境界でない辺」として扱われます。隅棟瓦のキャップ(巴瓦・鬼瓦)を谷に配置したくない場合は、手動で調整してください
- **湾曲屋根は非対応**: 瓦オブジェクトをピッチで複製・配置する仕組み上、瓦ごとにメッシュを再構築する必要がある湾曲屋根には対応していません
- **パース用途を想定**: 施工図面としての寸法精度は保証しません。谷などの複雑な形状は、最終的に手動で微調整する前提で設計されています
